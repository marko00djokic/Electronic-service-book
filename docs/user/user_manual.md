# ESB — Korisnički manual

## 1. Uvod u aplikaciju

Electronic Service Book (ESB) je digitalna servisna knjižica za automobile.
Omogućava serviserima da vode kompletnu evidenciju o vozilima i servisnim nalozima,
a vlasnicima automobila pruža uvid u servisnu istoriju njihovog vozila putem web portala.

**Aplikacija radi potpuno offline** — nije potrebna internet veza za svakodnevni rad.
Sinhronizacija sa cloud-om se dešava automatski u pozadini kada je internet dostupan.

---

## 2. Instalacija na Windows računar

*Popunjava se u Fazi 6.*

1. Preuzmi instaler: `ESB-Setup-x.x.x.exe`
2. Pokreni instaler i prati wizard
3. Aplikacija se instalira u `C:\Program Files\Electronic Service Book\`
4. Prečica se kreira na Desktopu i u Start meniju

**Sistemski zahtevi:**
- Windows 10 ili noviji (64-bit)
- 4 GB RAM (preporučeno)
- 500 MB slobodnog prostora na disku
